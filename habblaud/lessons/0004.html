Instale e valide o acesso local

Instalação e integrações

Entenda e aplique

Na pasta reservada à ferramenta, obtenha o código do repositório oficial e instale as dependências de compilação. Escolha uma única forma de execução para o primeiro teste: Docker, que precisa de seu serviço ativo, ou compilação e execução pelo Node. Use o roteiro desta aula e registre qualquer erro completo, retirando segredos.

Abra o endereço local indicado pela inicialização. A página carregar valida a primeira camada, mas ainda não comprova a detecção de contas ou o envio de mensagens. Registre três resultados separadamente: servidor iniciado, interface acessível e sessão de teste visível. Se a porta estiver ocupada, identifique a instância existente antes de iniciar outra.

Obter o projeto oficial

git clone https://github.com/marmottajr/habblaud.git
cd habblaud
npm install

Opção A — Docker

npm run docker:up

Opção B — Node, sem Docker

npm run build
npm start

Conferir

Abra http://localhost:4747. Execute apenas uma das opções de inicialização. No Windows, siga o caminho de instalação oficial compatível com seu ambiente; não misture pastas e processos de Windows e WSL sem conferir o mapeamento.

Exemplo fictício

Caio abre a interface, mas a sala de laboratório está vazia. Ele marca servidor e página como validados e mantém detecção de sessão como pendência.

Sua prática

Execute um dos caminhos do roteiro, abra o endereço local e registre horário, método, versão e os três resultados de validação.

Salvo neste navegador quando o armazenamento estiver disponível. Exporte uma cópia pelo caderno.
