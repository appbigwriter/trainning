Conecte o Claude Code e confira o mod

Instalação e integrações

Entenda e aplique

Para usar o Claude Code, abra uma sessão de laboratório na ferramenta de origem. O mod complementa o acompanhamento e os recursos disponíveis em versões compatíveis. Instale a integração conforme o roteiro oficial e confira o estado por conta. Uma conta detectada e uma integração ativa são verificações diferentes.

Sessões que já estavam abertas podem precisar recarregar os plugins ou ser reabertas. Depois disso, envie um pedido simples de leitura e acompanhe a mudança de atividade. Registre qual conta foi usada, sem anotar credenciais. Se houver integração antiga, siga a migração documentada para evitar duas configurações disputando o mesmo evento.

Na pasta de instalação do Habblaud

npm run mod:install
npm run mod:status

Na sessão do Claude Code já aberta

/reload-plugins

Exemplo fictício

Ana instala o mod em uma conta, mas testa uma sessão de outra. Ao conferir o status por conta, identifica por que o comportamento é diferente.

Sua prática

Confira o status, abra ou recarregue uma sessão compatível e faça uma tarefa de leitura. Registre conta, evento observado e resultado.

Salvo neste navegador quando o armazenamento estiver disponível. Exporte uma cópia pelo caderno.

Uma conta aparecer no escritório prova que o mod está ativo?
