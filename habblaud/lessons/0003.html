Prepare ambiente e plano de instalação

Fundamentos e preparação

Entenda e aplique

Separe a pasta de instalação do Habblaud da pasta usada pelos agentes para praticar. Registre sistema operacional, versão do Node, presença do Git, opção Docker ou Node e ferramenta de origem. Isso torna os erros reproduzíveis e evita executar comandos na pasta errada.

A página oficial oferece instalação guiada, inclusive orientação para Windows com WSL2. O manual técnico consultado detalha requisitos de Node 22.12 ou superior e caminhos para Docker e Node. Como os documentos podem evoluir em ritmos diferentes, confira as instruções da sua plataforma antes de executar. Um comando de Bash não deve ser colado como configuração de PowerShell sem adaptação.

Inventário do ambiente

node --version
npm --version
git --version
# Se escolher Docker:
docker --version
docker compose version

Exemplo fictício

Bia usa Windows e anota que seguirá o roteiro oficial para WSL2. Ela identifica em qual ambiente ficam os arquivos dos agentes antes de tentar conectar o escritório.

Sua prática

Preencha uma matriz com sistema, shell, Node, Git, Docker, pastas e caminho escolhido. Marque o que ainda não verificou.

Salvo neste navegador quando o armazenamento estiver disponível. Exporte uma cópia pelo caderno.
